Entrega 4 — Consultas SQL de negocio

Objetivo
El objetivo de esta entrega es realizar consultas SQL sobre la base de datos ventas_tech_db para obtener métricas relevantes para el análisis del negocio.

Consultas realizadas

Se trabajó sobre la tabla ventas para obtener:
Resumen ejecutivo mensual: total facturado, cantidad de pedidos y ticket promedio.
Ranking de productos: Top 5 de productos según facturación y unidades vendidas.
Clientes recurrentes: clientes con más de un pedido y su gasto total.
Comparación mensual: facturación de cada mes respecto del promedio mensual.

Hallazgos
1)El 55% de la facturación correspondiente a los primeros 15 días de Marzo proviene del producto ID 1(Laptop pro15).
2)El producto ID 4(Auriculares BT Pro) fue el menos vendido y representa un 3% de la facturación total de la primera quincena de Marzo.
3)El cliente ID 1 fue el mayor comprador y represento el 40% de la facturación total de la primera quincena de Marzo.
